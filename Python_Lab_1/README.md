# Python Lab 1: TCP Web Server

## Run

```bash
python3 WebServer.py
```

Open this URL in a browser:

```text
http://127.0.0.1:6789/HelloWorld.html
```

## Files

- `WebServer.py`: completed socket-based HTTP server.
- `HelloWorld.html`: sample HTML file served by the server.

## Screenshot

`browser-screenshot.png` shows the rendered `HelloWorld.html` page being received from the socket server. If you want a fresh screenshot, start the server, open the URL above in your browser, and capture the page.
